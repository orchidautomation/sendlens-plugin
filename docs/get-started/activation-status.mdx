<Warning>
  Paid activation is not available in the current OSS release line.
</Warning>

The current MIT release installs from public GitHub release assets and does not require a SendLens product license. There is no released `sendlens login`, license-status, renewal, deactivation, recovery, or offline-grace command in v0.1.76.

## Tracked but not released

| Surface | Current status |
| --- | --- |
| Future source and license terms | Human and legal decision required |
| Price, package, seats, devices, workspaces, agency use, refunds, and support | Decision in progress |
| Purchase-to-paid-use proof | Sandbox proof not complete |
| Host-specific sign-in and compatibility | Depends on sandbox proof |
| Private installer and released-artifact proof | Requires installer hardening and clean-host proof |

## What this means for readers

- Use the [current MIT installer](/docs/get-started/install) for released OSS behavior.
- Do not infer a paid command or private download URL from placeholders in these docs.
- Do not infer pricing, update rights, offline behavior, refund terms, support levels, or agency allowances.
- Treat future commercial instructions as unavailable until they are implemented, verified, and approved for publication.

This page is a release-state boundary, not a waitlist or purchase page.
