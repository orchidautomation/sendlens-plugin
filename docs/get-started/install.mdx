</Warning>

## Requirements

- macOS or Linux
- Node.js
- `curl`, `bash`, `mktemp`, and network access
- one supported host: Claude Code, Cursor, Codex, or OpenCode

The public installer verifies release metadata and checksums. It does not require a globally installed Pluxx CLI.

## Install all supported hosts

```bash
bash <(curl -fsSL https://sendlens.app/install.sh) --agents -y
```

## Run the first check

Reload or restart the host, then run:

```text
/sendlens-setup
```

Setup checks the installed surface, helps connect a provider, and can initialize a synthetic demo workspace when no provider key is configured.

<Note>
  Demo results are synthetic. They demonstrate the workflow but must not be used to judge a real campaign or workspace.
</Note>
